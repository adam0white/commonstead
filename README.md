# Commonstead

A ten-minute residential workshop near Alder Quay with eight Human Framework people. Build a storehouse before the storm to keep the shared supplies dry. Direct control gives way to fatigue, recovery and remembered pressure.

- `npm ci`
- `npm run dev`
- `npm run ci` — lint, strict typecheck, focused tests, stamped build.
- `npm run deploy` — clean tree and green exact-commit GitHub ci required.

Design and owner acceptance boundary: [docs/concept.md](docs/concept.md). Reviews: [docs/reviews](docs/reviews/). Original Canvas art and text; no game assets or code borrowed from commercial or open-source RTS games. Static assets only. HF 2.21.0 (engine 2.21.0) owns people; this host owns map and economy.

Current cast, continuity and native sender contract: [docs/cast-adoption.md](docs/cast-adoption.md). Exactly eight canonical residents open together. Browser continuity is optional; file imports and mixed histories have separate recording gates. Dynamic release and browser receipts live outside source at `~/code/.lab-scratch/cast/commonstead.md`.
